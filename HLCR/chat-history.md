Press Ctrl + A (Windows/Linux) or Cmd + A (Mac) to highlight the entire chat history.
Press Ctrl + C or Cmd + C to copy the text.
Open a new file in VS Code by pressing Ctrl + N or Cmd + N.
Paste the chat history into the new file using Ctrl + V or Cmd + V.
Save the file (Ctrl + S or Cmd + S) as chat-history.txt.
You can now upload this .txt file directly to the Google Gemini web page or simply copy the specific parts you need from it!

Method 2: VS Code's Built-in Chat Export (JSON format)
Because Gemini Code Assist integrates with VS Code's native Chat interface, you can also use VS Code's built-in export tool. Note that this saves as a .json file, which includes a lot of background metadata, so it's a bit messier to read manually.

Open the VS Code Command Palette by pressing Ctrl + Shift + P (Windows/Linux) or Cmd + Shift + P (Mac).
Type Chat: Export Session and press Enter.
A prompt will appear asking where you want to save the .json file.
Save the file to your computer.
If your goal is just to share the context with the web version of Gemini, Method 1 is highly recommended because it strips out the metadata and leaves you with the raw conversation!
